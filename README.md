Задача:
Создать bash-скрипт автоматизирующий настройку веб-сервера nginx

Скрипт должен:
1. Обновлять все пакеты системы Ubuntu
2. Установка пакета nginx
3. Создание директории для html-файла и conf-файла nginx
4. Создаине файлов и заполнение данными html-файла и conf-файла nginx
5. Проверка nginx-конфига и перезапуск сервера
7. Установка пакета curl, если пакет не установлен
8. Добавляем локальный сервер и имя сервера в /etc/hosts
9. Проверяем сайт на работоспособность
